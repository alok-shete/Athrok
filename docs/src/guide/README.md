# Introduction

Welcome to Athrok, a versatile and type-safe state management library designed for React and React Native applications. Athrok simplifies state management by providing both simple state management with hooks (`createState`) and more complex state management with stores (`createStore`).

## Key Features

- **Type-Safe**: Athrok leverages TypeScript to ensure type safety throughout your application.
- **Easy Integration**: Designed to be easily integrated into new or existing projects.
- **Flexible API**: Offers a flexible API for both simple state management and more complex state and actions management.
- **React and React Native Support**: Works seamlessly across both React and React Native platforms.

## State Persistence

Athrok does not include built-in persistence solutions. Instead, it provides flexibility to integrate with various storage solutions for state persistence such as async storage, local storage, and MMKV.


## Why Athrok?
Athrok was created to provide a straightforward yet powerful solution to managing application state in modern JavaScript applications. Whether you're building a small prototype or a large-scale application, Athrok can help you manage your state effectively and efficiently.
